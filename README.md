# jakhmola.github.io

A self-updating portfolio at **https://jakhmola.github.io**. The site is never edited by hand: a **Scheduled Rebuild** (GitHub Actions — daily cron, manual dispatch, or any push to `main`) regenerates it from the GitHub API and redeploys to GitHub Pages.

## How it works

```
fetch repos ──> filter ──> rank ──> summarize Featured ──> render ──> bundle ──> deploy dist/
 (GitHub API)  (no forks,  (pure    (GitHub Models LLM,    (static    (esbuild:   (Pages, from
                profile,    score)   cached by README hash)  HTML/CSS)  three +     the Actions
                hidden)                                                 gsap)       artifact)
```

- **Ranking** is a pure function scoring README depth, description presence, push recency, and stars. The top ~6 become **Featured Projects** with full cards; the rest render as a compact list.
- **Summaries** are two recruiter-oriented sentences per Featured Project, generated by the free GitHub Models endpoint with the workflow's own `GITHUB_TOKEN` and cached in `.cache/summaries.json` (persisted via `actions/cache`, keyed by README content hash). Per ADR 0001 the LLM is never load-bearing: any failure falls back to the cached Summary, then the raw repo description — the build never fails because of the LLM.
- The only hand-authored material is **Seed Content** in `site.config.json` (hero/about copy, contact links, supplemental skills) plus `static/resume.pdf`.
- The page is a scroll-driven WebGL experience: `app/` renders one GPU particle field that morphs through a formation per beat — the whole account as a disc, the ranking as a funnel, then a distinct procedural solid per Featured Project, seeded from repo identity (or from a form word the LLM returns alongside the Summary). **Every visual is computed at runtime**; the repo ships no images or video.
- The field is strictly additive. All copy is server-rendered into `index.html`, so a blocked bundle, a dead WebGL context, or `prefers-reduced-motion` all still leave a complete, readable page. Same rule as the LLM, per ADR 0001.

## Topic Overrides

Steer the site from GitHub, no code changes:

| Topic on a repo     | Effect                                                                  |
| ------------------- | ----------------------------------------------------------------------- |
| `portfolio-feature` | Always a Featured Project, regardless of score — even if it is a fork   |
| `portfolio-hide`    | Never appears on the site at all (beats `portfolio-feature`)            |

Forks and the profile repo (`Jakhmola/Jakhmola`) are otherwise always excluded. The fork escape hatch exists because GitHub flags `career-ops` as a fork (parent deleted) even though it is active original work.

## Development

Node ≥ 20. The build pipeline itself has no runtime dependencies; the front end
uses `three` and `gsap`, bundled by `esbuild`.

```sh
npm ci                    # three, gsap, esbuild
npm test                  # node:test, fully offline (fixtures)
npm run build             # live build from the GitHub API + bundle -> dist/
npm run build:fixtures    # offline build from fixture JSON + bundle -> dist/
npm run bundle            # app/ -> dist/app.js only
```

To look at it locally: `npm run build:fixtures && (cd dist && python3 -m http.server 8765)`.
